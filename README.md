# 26상 슈퍼루키 제안서 — Consent by Gesture

> 가리는 게 기본, 보여주는 건 선택 — 사람을 기본적으로 보호하고, 동의한 사람만 담는 스마트 글래스 촬영 경험

MX 사업부 / 스마트 글래스(Galaxy Glass) × Galaxy 스마트폰 연동 촬영 경험 제안서 장표입니다.

## 배포

- 배포 링크: https://ooohje.github.io/super_rookie_html/
- `index.html` 한 파일로 7페이지 전체가 들어 있습니다. 브라우저에서 `Ctrl+P` 로 인쇄하면 페이지당 1장으로 PDF가 만들어집니다.

## 구성

| 페이지 | 내용 |
| --- | --- |
| 1 | 제안 분야 · 아이디어 제목 · 개요 (As-is / To-be, 경험 플로우) |
| 2 | 제안 배경 (LED 고지 방식의 한계, 선행 연구) |
| 3 | 제안 내용 ① 핵심 기능 (기본 마스킹 · 제스처 허용 · 개인별 언마스킹) |
| 4 | 제안 내용 ② 사용자 시나리오 · 시스템 구성 · 데이터 원칙 |
| 5 | 제안 내용 ③ 기술 구현 QnA · 삼성 기술 연계 · 로드맵 |
| 6 | 차별화 포인트 · 경쟁 방식 비교 |
| 7 | 기대효과 · 참고문헌 |
